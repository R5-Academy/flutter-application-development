# Compartilhamento de Estado

Código da aula **Compartilhamento de Estado** (InheritedWidget: Compartilhando Dados pela Árvore) do curso **Flutter Application Development** — R5 Flutter Academy.

## O que tem aqui

- `exemplo_compartilhamento_de_estado_codigo_final/` — o projeto **como ficou ao fim da gravação**.
- `exemplo_compartilhamento_de_estado/` — o **ponto de partida**: mesmo projeto com a `lib/` no estado em que a aula começa.

## Como baixar

Só esta aula, com git:

```bash
git clone -b 06-04-compartilhamento-de-estado --single-branch https://github.com/R5-Academy/flutter-application-development.git 06-04-compartilhamento-de-estado
```

Sem git: [baixar o ZIP](https://github.com/R5-Academy/flutter-application-development/archive/refs/heads/06-04-compartilhamento-de-estado.zip).

Depois, dentro da pasta do projeto: `flutter pub get` e `flutter run`.

Sobre o curso: <https://github.com/R5-Academy/flutter-application-development>
