# showModalBottomSheet

Código da aula **showModalBottomSheet** (Diálogos e Feedback) do curso **Flutter Application Development** — R5 Flutter Academy.

## O que tem aqui

- `exemplo_modalbottomsheet_codigo_final/` — o projeto **como ficou ao fim da gravação**.
- `exemplo_modalbottomsheet/` — o **ponto de partida**: mesmo projeto com a `lib/` no estado em que a aula começa.

## Como baixar

Só esta aula, com git:

```bash
git clone -b 04-03-showmodalbottomsheet --single-branch https://github.com/R5-Academy/flutter-application-development.git 04-03-showmodalbottomsheet
```

Sem git: [baixar o ZIP](https://github.com/R5-Academy/flutter-application-development/archive/refs/heads/04-03-showmodalbottomsheet.zip).

Depois, dentro da pasta do projeto: `flutter pub get` e `flutter run`.

Sobre o curso: <https://github.com/R5-Academy/flutter-application-development>
