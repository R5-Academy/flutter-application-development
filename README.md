# Async: Armadilhas

Código da aula **Async: Armadilhas** (Async na Interface) do curso **Flutter Application Development** — R5 Flutter Academy.

## O que tem aqui

- `exemplo_async_e_lifecycle_codigo_final/` — o projeto **como ficou ao fim da gravação**.
- `exemplo_async_e_lifecycle/` — o **ponto de partida**: mesmo projeto com a `lib/` no estado em que a aula começa.

## Como baixar

Só esta aula, com git:

```bash
git clone -b 07-07-async-armadilhas --single-branch https://github.com/R5-Academy/flutter-application-development.git 07-07-async-armadilhas
```

Sem git: [baixar o ZIP](https://github.com/R5-Academy/flutter-application-development/archive/refs/heads/07-07-async-armadilhas.zip).

Depois, dentro da pasta do projeto: `flutter pub get` e `flutter run`.

Sobre o curso: <https://github.com/R5-Academy/flutter-application-development>
