# SnackBar e ScaffoldMessenger

Código da aula **SnackBar e ScaffoldMessenger** (Diálogos e Feedback) do curso **Flutter Application Development** — R5 Flutter Academy.

## O que tem aqui

- `exemplo_snackbar_scaffoldmessager_codigo_final/` — o projeto **como ficou ao fim da gravação**.
- `exemplo_snackbar_scaffoldmessager/` — o **ponto de partida**: mesmo projeto com a `lib/` no estado em que a aula começa.

## Como baixar

Só esta aula, com git:

```bash
git clone -b 04-04-snackbar-e-scaffoldmessenger --single-branch https://github.com/R5-Academy/flutter-application-development.git 04-04-snackbar-e-scaffoldmessenger
```

Sem git: [baixar o ZIP](https://github.com/R5-Academy/flutter-application-development/archive/refs/heads/04-04-snackbar-e-scaffoldmessenger.zip).

Depois, dentro da pasta do projeto: `flutter pub get` e `flutter run`.

Sobre o curso: <https://github.com/R5-Academy/flutter-application-development>
