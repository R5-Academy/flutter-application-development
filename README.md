# StreamBuilder

Código da aula **StreamBuilder** (Async na Interface) do curso **Flutter Application Development** — R5 Flutter Academy.

## O que tem aqui

- `exemplo_streambuilder_codigo_final/` — o projeto **como ficou ao fim da gravação**.
- `exemplo_streambuilder/` — o **ponto de partida**: mesmo projeto com a `lib/` no estado em que a aula começa.

## Como baixar

Só esta aula, com git:

```bash
git clone -b 07-02-streambuilder --single-branch https://github.com/R5-Academy/flutter-application-development.git 07-02-streambuilder
```

Sem git: [baixar o ZIP](https://github.com/R5-Academy/flutter-application-development/archive/refs/heads/07-02-streambuilder.zip).

Depois, dentro da pasta do projeto: `flutter pub get` e `flutter run`.

Sobre o curso: <https://github.com/R5-Academy/flutter-application-development>
