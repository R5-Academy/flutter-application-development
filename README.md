# MaterialPageRoute

Código da aula **MaterialPageRoute** (Navegação) do curso **Flutter Application Development** — R5 Flutter Academy.

## O que tem aqui

- `exemplo_materialpageroute_codigo_final/` — o projeto **como ficou ao fim da gravação**.
- `exemplo_materialpageroute/` — o **ponto de partida**: mesmo projeto com a `lib/` no estado em que a aula começa.

## Como baixar

Só esta aula, com git:

```bash
git clone -b 03-06-materialpageroute --single-branch https://github.com/R5-Academy/flutter-application-development.git 03-06-materialpageroute
```

Sem git: [baixar o ZIP](https://github.com/R5-Academy/flutter-application-development/archive/refs/heads/03-06-materialpageroute.zip).

Depois, dentro da pasta do projeto: `flutter pub get` e `flutter run`.

Sobre o curso: <https://github.com/R5-Academy/flutter-application-development>
