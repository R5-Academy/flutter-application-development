# InheritedWidget

Código da aula **InheritedWidget** (InheritedWidget: Compartilhando Dados pela Árvore) do curso **Flutter Application Development** — R5 Flutter Academy.

## O que tem aqui

- `exemplo_inheritedwidget_codigo_final/` — o projeto **como ficou ao fim da gravação**.
- `exemplo_inheritedwidget/` — o **ponto de partida**: mesmo projeto com a `lib/` no estado em que a aula começa.

## Como baixar

Só esta aula, com git:

```bash
git clone -b 06-01-inheritedwidget --single-branch https://github.com/R5-Academy/flutter-application-development.git 06-01-inheritedwidget
```

Sem git: [baixar o ZIP](https://github.com/R5-Academy/flutter-application-development/archive/refs/heads/06-01-inheritedwidget.zip).

Depois, dentro da pasta do projeto: `flutter pub get` e `flutter run`.

Sobre o curso: <https://github.com/R5-Academy/flutter-application-development>
