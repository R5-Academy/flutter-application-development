# ListenableBuilder

Código da aula **ListenableBuilder** (Gerenciamento de Estado Nativo) do curso **Flutter Application Development** — R5 Flutter Academy.

## O que tem aqui

- `exemplo_listenablebuilder_codigo_final/` — o projeto **como ficou ao fim da gravação**.
- `exemplo_listenablebuilder/` — o **ponto de partida**: mesmo projeto com a `lib/` no estado em que a aula começa.

## Como baixar

Só esta aula, com git:

```bash
git clone -b 05-05-listenablebuilder --single-branch https://github.com/R5-Academy/flutter-application-development.git 05-05-listenablebuilder
```

Sem git: [baixar o ZIP](https://github.com/R5-Academy/flutter-application-development/archive/refs/heads/05-05-listenablebuilder.zip).

Depois, dentro da pasta do projeto: `flutter pub get` e `flutter run`.

Sobre o curso: <https://github.com/R5-Academy/flutter-application-development>
