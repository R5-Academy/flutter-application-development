# PageStorageKey: Preservando o Scroll

Código da aula **PageStorageKey: Preservando o Scroll** (Preservando o Estado da Tela) do curso **Flutter Application Development** — R5 Flutter Academy.

## O que tem aqui

- `exemplo_pagestoragekey_preservando_o_scroll_codigo_final/` — o projeto **como ficou ao fim da gravação**.
- `exemplo_pagestoragekey_preservando_o_scroll/` — o **ponto de partida**: mesmo projeto com a `lib/` no estado em que a aula começa.

## Como baixar

Só esta aula, com git:

```bash
git clone -b 08-01-pagestoragekey-preservando-o-scroll --single-branch https://github.com/R5-Academy/flutter-application-development.git 08-01-pagestoragekey-preservando-o-scroll
```

Sem git: [baixar o ZIP](https://github.com/R5-Academy/flutter-application-development/archive/refs/heads/08-01-pagestoragekey-preservando-o-scroll.zip).

Depois, dentro da pasta do projeto: `flutter pub get` e `flutter run`.
