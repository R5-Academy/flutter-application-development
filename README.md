# Splash Screen na Prática

Código da aula **Splash Screen na Prática** (Recursos Nativos do App) do curso **Flutter Application Development** — R5 Flutter Academy.

## O que tem aqui

- `exemplo_splash_screen_na_pratica_codigo_final/` — o projeto **como ficou ao fim da gravação**.
- `exemplo_splash_screen_na_pratica/` — o **ponto de partida**: mesmo projeto com a `lib/` no estado em que a aula começa.

## Como baixar

Só esta aula, com git:

```bash
git clone -b 09-06-splash-screen-na-pratica --single-branch https://github.com/R5-Academy/flutter-application-development.git 09-06-splash-screen-na-pratica
```

Sem git: [baixar o ZIP](https://github.com/R5-Academy/flutter-application-development/archive/refs/heads/09-06-splash-screen-na-pratica.zip).

Depois, dentro da pasta do projeto: `flutter pub get` e `flutter run`.

Sobre o curso: <https://github.com/R5-Academy/flutter-application-development>
