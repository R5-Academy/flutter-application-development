# AppLifecycleListener

Código da aula **AppLifecycleListener** (Ciclo de Vida do App) do curso **Flutter Application Development** — R5 Flutter Academy.

## O que tem aqui

- `exemplo_applifecyclelistener_codigo_final/` — o projeto **como ficou ao fim da gravação**.
- `exemplo_applifecyclelistener/` — o **ponto de partida**: mesmo projeto com a `lib/` no estado em que a aula começa.

## Como baixar

Só esta aula, com git:

```bash
git clone -b 02-03-applifecyclelistener --single-branch https://github.com/R5-Academy/flutter-application-development.git 02-03-applifecyclelistener
```

Sem git: [baixar o ZIP](https://github.com/R5-Academy/flutter-application-development/archive/refs/heads/02-03-applifecyclelistener.zip).

Depois, dentro da pasta do projeto: `flutter pub get` e `flutter run`.

Sobre o curso: <https://github.com/R5-Academy/flutter-application-development>
