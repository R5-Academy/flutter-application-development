# showDialog e AlertDialog

Código da aula **showDialog e AlertDialog** (Diálogos e Feedback) do curso **Flutter Application Development** — R5 Flutter Academy.

## O que tem aqui

- `exemplo_dialog_e_alert_codigo_final/` — o projeto **como ficou ao fim da gravação**.
- `exemplo_dialog_e_alert/` — o **ponto de partida**: mesmo projeto com a `lib/` no estado em que a aula começa.

## Como baixar

Só esta aula, com git:

```bash
git clone -b 04-01-showdialog-e-alertdialog --single-branch https://github.com/R5-Academy/flutter-application-development.git 04-01-showdialog-e-alertdialog
```

Sem git: [baixar o ZIP](https://github.com/R5-Academy/flutter-application-development/archive/refs/heads/04-01-showdialog-e-alertdialog.zip).

Depois, dentro da pasta do projeto: `flutter pub get` e `flutter run`.

Sobre o curso: <https://github.com/R5-Academy/flutter-application-development>
