# InheritedNotifier

Código da aula **InheritedNotifier** (InheritedWidget: Compartilhando Dados pela Árvore) do curso **Flutter Application Development** — R5 Flutter Academy.

## O que tem aqui

- `exemplo_inheritednotifier_codigo_final/` — o projeto **como ficou ao fim da gravação**.
- `exemplo_inheritednotifier/` — o **ponto de partida**: mesmo projeto com a `lib/` no estado em que a aula começa.

## Como baixar

Só esta aula, com git:

```bash
git clone -b 06-02-inheritednotifier --single-branch https://github.com/R5-Academy/flutter-application-development.git 06-02-inheritednotifier
```

Sem git: [baixar o ZIP](https://github.com/R5-Academy/flutter-application-development/archive/refs/heads/06-02-inheritednotifier.zip).

Depois, dentro da pasta do projeto: `flutter pub get` e `flutter run`.

Sobre o curso: <https://github.com/R5-Academy/flutter-application-development>
